# LinguaLearn

## Project Description
LinguaLearn is an online language learning platform where students can learn French, English, Spanish, Japanese, Russian, Italian, Swahili, German, Arabic, and Mandarin.

Students can enroll in courses, complete lessons, take quizzes, and track their learning progress. Instructors can create and manage language courses.
